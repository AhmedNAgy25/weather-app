# Weather App ☀️🌦️

## Features ✨
- **Real-Time Weather Data:** Fetches current weather details (temperature, humidity, wind speed, and conditions) for any city.
- **Search by City:** 🔍 Quickly retrieve weather information by entering a city's name.
- **Responsive Design:** 📱 Optimized layout for both desktop and mobile devices.
- **API Integration:** 🔗 Uses the OpenWeatherMap API to ensure reliable and up-to-date weather information.

## Quick Start 🚀
1. **Clone the repository:**
   ```bash
   git clone https://github.com/AhmedNAgy25/weather-app.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd weather-app
   ```
3. **Open the application:**
   - Simply open the `index.html` file in your web browser.
   - For a better development experience, consider using a local server (e.g., [Live Server for VS Code](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)).

## Project Structure 📁
```
weather-app/

## Customization 🔧
- **API Key Setup:**  
  Obtain an API key from [OpenWeatherMap](https://openweathermap.org/api) and insert it into `app.js`:
  ```javascript
  const API_KEY = 'YOUR_API_KEY_HERE';
  ```
- **Styling:**  
  🎨 Modify `style.css` to update the look and feel of the app.
- **Feature Enhancements:**  
  🚀 Extend the app's functionality (e.g., add a forecast feature or location-based weather) by updating the JavaScript code.
